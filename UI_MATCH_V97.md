# SocialNova V97 — UI Match Release

This release updates the Flutter client to closely match the supplied SocialNova design references.

## Implemented
- Home header rebuilt around the supplied SocialNova launcher artwork.
- Home top navigation: `لك / أتابعه / الأصدقاء / استكشف / مباشر`.
- Following and friends tabs filter the real feed using the existing follow/follower APIs.
- Explore and Live tabs open their existing functional screens.
- Bottom navigation rebuilt to: `الرئيسية / استكشف / إنشاء / الرسائل / الملف الشخصي`.
- Create button remains connected to the existing post/reel composer.
- Notification and message indicators remain actionable.
- Story rail enlarged and restyled to match the supplied circular neon story layout.
- Global neon palette tuned toward the supplied deep-blue / electric-blue / violet reference.
- Existing LiveKit live rooms, gift sending, story viewer, comments, likes, reposts, bookmarks and sharing logic are preserved.
- Gift store surface enlarged to use the supplied full-screen neon presentation more closely.
- Login/register logo updated to the supplied SocialNova artwork.

## Version
Flutter build: `3.7.0+19`
