# SocialNova V6

- Professional Arabic-first dark/glass social UI.
- Messenger inbox + direct chat with Socket.IO realtime delivery.
- Reels publishing form and vertical video viewer.
- Stories publishing and story rail.
- Groups creation, join/leave and group chat.
- Live room UI with realtime live chat over Socket.IO. Actual camera/video broadcasting requires LiveKit credentials (`LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`) and can be connected to the existing backend room model.
- Professional profile with posts/followers/following counters, bio, website, location and birthday fields.
- Profile editing and settings/notifications screens.
- Search users.
- Branded launcher icon and redesigned login/register screen.
- Android build targets Java/Kotlin JVM 17.
- GitHub Actions defaults point to the current Render API URL used by the project.
