# SocialNova V80 — Profile Status Rings + Live Interaction

## Changes
- Profile status ring segments are individually tappable: LIVE, STORY, POST, REEL.
- LIVE segment opens the active LiveRoom directly.
- STORY opens the newest active story.
- POST opens the newest post.
- REEL opens the newest reel.
- Verified PRO badge now has an animated gold glow; NORMAL verification keeps a blue glowing badge.
- Live header shows host avatar, display name and username.
- Live header avatar opens the host profile.
- Live header includes a follow `+` action for viewers.
- Live tapping is now double-tap on the screen instead of a dedicated heart button.
- Double-tap sends the live tap event and shows a heart feedback animation.
- Existing live viewer, tap and gift counters remain visible.

No existing feature was intentionally removed; the dedicated heart control was replaced by screen double-tap as requested.
