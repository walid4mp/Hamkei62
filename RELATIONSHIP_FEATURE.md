# SocialNova — Relationship Status

## What is included
- Profile relationship status: Single, In a relationship, Engaged, Married, Civil union, Domestic partnership, Open relationship, Complicated, Separated, Divorced, Widowed.
- Partner selection is limited to people who follow the current user.
- A relationship request requires the selected partner to accept it before it becomes active.
- Once accepted, both profiles show the same status, partner name/avatar, and the relationship start date.
- Gender-aware Arabic labels: رجل/امرأة get matching forms such as مخطوب/مخطوبة and متزوج/متزوجة.
- Pending requests can be accepted or rejected from the profile card.
- Ending an active relationship resets both profiles to Single.
- Date can be selected from the profile editor.
- Backend schema is applied automatically by the existing Render Docker startup command (`prisma db push`).
