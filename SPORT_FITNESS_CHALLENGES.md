# SocialNova — Fitness Challenges

Added a local-first fitness challenge hub with:
- Daily/weekly activity challenges.
- Steps/activity logging placeholder, hydration logging, running distance, home activity, and short activity challenges.
- Progress bars and completion states.
- Personal progress stored locally with SharedPreferences.
- Group participation toggle and local team points.
- Sports achievement entry point.
- Seasonal/group challenges can be added to the same model later.
- Privacy copy clarifies that health data is not shared without permission.

The current release does not automatically read Health Connect/HealthKit data. That can be connected later with explicit user permissions.
