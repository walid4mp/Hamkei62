# SocialNova V102 — Full Project Package

This archive contains the complete source tree carried by V101, including:
- Flutter Android application under `flutter-app/`
- Node/Express backend under `backend/`
- Admin panel under `admin-panel/`
- GitHub Actions under `.github/workflows/`
- Android Gradle wrapper and project files
- Prisma schema and backend package-lock
- application assets and gift assets
- tests and documentation

The package intentionally excludes generated build/cache directories (`build/`, `.dart_tool/`, `node_modules/`, coverage output) and production secrets such as keystores, API keys, and `google-services.json`.

V102 includes the V101 CI source fixes for the creator content center and Home discovery widgets.
